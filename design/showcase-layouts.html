Work showcase · five layouts

Same screenshots, same captions, five structures

Nothing here changes what you show. Every one uses your existing screenshot, your existing copy, the chips, the tech rows and the CTA. What differs is the arrangement: where the media sits, how wide it gets, what holds the block together, and what happens across four projects in a row.

Three of them render two projects so you can see the rhythm repeat, which is the one thing a single block cannot show you. The second block reuses the same screenshot because I only pulled one out of the page — look at the structure repeating, not at the picture.

1

Sidebar and stage

what ships today, tuned

Your current structure: text in one column, media in two, hairline between projects. Tuned rather than redesigned — the title drops to 30px so it stops wrapping to four lines in a 300px column, and the tech rows get a label column so they read as data rather than as decoration.

For You already have it. Dense, and the narrow text column keeps the prose at a sane measure without any max-width fighting the grid.
Against The text column is only 300px, so a long title has nowhere to go. Four identical blocks in a row read as a list of the same thing.

Media over, text under

blog.google article shape

The screenshot spans the whole column and the text sits beneath it, split into a wide prose column and a narrow meta column. The media gets 966px instead of 640, and the title gets the full width so it sets on one or two lines instead of four.

For Biggest possible screenshot, by a lot. The title finally has room. This is the shape blog.google uses for a story: artwork first, then the writing under it.
Against Tallest of the five, so four projects is a long scroll. The media and the text stop being a pair and become a sequence.

Alternating

deepmind.google

Equal halves, and the sides swap on every project. Same components as today, but the eye stops predicting the layout, which is the cheapest fix for four blocks reading as one.

For Kills the monotony with no new components and no extra height. Equal columns give the text more room than the current third.
Against The media drops to 462px, smaller than today. Alternation can feel like a template if the projects are not visually distinct.

4

Contained card

fonts.google.com

Each project becomes one card on the tonal surface, 28px radius, with the screenshot inset inside it. The card does the separating, so the hairlines go. Corners respond on hover, which is Google's current signature and is safe here because a card carries no rule.

For The block finally reads as one object rather than as two columns that happen to be adjacent. Uses the tonal ramp that now works in both themes.
Against The most surface your site has ever had. Four filled cards in a row is a big departure from a page that is currently all ground and hairlines.
